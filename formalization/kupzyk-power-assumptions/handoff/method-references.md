# Method reference metadata

The following references are relevant to methods used in this replication. Use
a citation only when the associated method is discussed. The dissertation is
the source for the numerical claims and methodological details of the original
design.

- Bates, Douglas, Martin Mächler, Ben Bolker, and Steve Walker (2015).
  Fitting Linear Mixed-Effects Models Using lme4. Journal of Statistical
  Software, 67(1). DOI 10.18637/jss.v067.i01. This is the reference for the
  independent lme4 validation engine.
- Halekoh, Ulrich, and Søren Højsgaard (2014). A Kenward–Roger Approximation
  and Parametric Bootstrap Methods for Tests in Linear Mixed Models:
  The R Package pbkrtest. Journal of Statistical Software, 59(9).
  DOI 10.18637/jss.v059.i09. This is the reference for the independent
  Kenward–Roger check. No bootstrap is used in the re-replication.
- Morris, Tim P., Ian R. White, and Michael J. Crowther (2019). Using
  simulation studies to evaluate statistical methods. Statistics in
  Medicine, 38(11), 2074–2102. DOI 10.1002/sim.8086. This is background for
  treating Monte Carlo error separately from discrepancies between methods.
- Kevin A. Kupzyk (2011). The Effects of Simplifying Assumptions in Power
  Analysis. PhD dissertation, University of Nebraska–Lincoln.
  https://digitalcommons.unl.edu/cehsdiss/106/. The original work identifies
  James A. Bovaird as advisor. Use dissertation page and table references
  for reported estimates.
