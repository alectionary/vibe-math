\section{Checked proofs, exact interfaces and reproduction}\label{app:lean}
The complete proof module imports only \texttt{Std}, using Lean 4.36.0-rc1.
Finite statements use kernel-evaluated \texttt{decide}; the graph walks,
spanning-tree propagation and eventual stopping arguments are structural
proofs. The bit-vector projection simplifier \texttt{bv\_normalize} produces
ordinary proof terms. No native decision or SAT certificate oracle is used.
Every theorem's audited dependencies are restricted to \texttt{propext},
\texttt{Classical.choice} and \texttt{Quot.sound}.

\subsection{Stopped executions, gate bridges and analytic formulas}
The source algorithm halts on a syndrome match. \texttt{stoppedOutput}
therefore repeats the accepted terminal word after time one; the already
proved first-step equalities make this a faithful representation for every
input. The witnesses $L=1$ prove both eventual quantifiers for all natural
times, and their negations rule out a trapping input. The remainder prints
the exact gate maps, the independent-basis interfaces, the supported-logical
consequence and the analytic vote/output descriptions.

\subsection{Reproduction and evidence levels}
Run \texttt{python3 build.py --lean /path/to/lean} in the artifact folder
with the pinned toolchain, then \texttt{python3 verify.py --check}.
The clean build reports every theorem's dependencies. The independent
literal-list implementation reconstructs the two CNOT maps, all $128$
inputs, complete binary spans and all $32,766$ nontrivial cuts. Its JSON
certificate supplies diagnostics, while Lean supplies the formal proofs.
The original fourteen-coordinate artifact remains preserved separately.
