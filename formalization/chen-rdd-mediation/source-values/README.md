# Values transcribed from Chen (2021)

Numbers printed in the dissertation, transcribed from the PDF text layer
(sha256 in `../source-inventory.json`). The PDF is not stored here.

- `table_4_8.csv`: Table 4.8, percentage of non-biased results (within +-.10 and +-.05) by effect and cut score index (PDF p. 102).
- `table_4_9.csv`: Table 4.9, percentage below the interval, coverage and above the interval (PDF p. 138).
- `table_3_1.csv`: Table 3.1 (and Table 1.1), the manipulated factors and levels.

Table 4.8's note labels cut score index 1 as 25% treatment and index 3 as 75% treatment.
Her printed code (Appendix A) assigns treatment above the 25th, 50th and 75th
percentiles, so index 1 has 75% treated. The replication follows the code; see
DISAGREEMENTS.yaml.

Tables 4.6-4.7 (Head Start estimates) are transcribed in `../secondary/table_arithmetic.csv`.
Chen's figures are digitized in `../results/digitized_bias.csv`, `../results/digitized_rates.csv`
and `../results/digitized_imbalance.csv`.
