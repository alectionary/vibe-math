singleton rank test, with the already authorized cap of20 rounds/10 minutes.
This recommendation is based on the current saved evidence, not a runtime or
convergence guarantee. The complementary orbit15 pilot is a single bounded

For any exact dual normal `c`, physical greedy optimization gives the full
support `h(c)`. A positive gap `c*q-h(c)` is already a global conditional
moment inequality after multiplication by the exact positive anchor mass.
It can also yield a simple subset-rank cut: sort `c` and use the signed-prefix
greedy identity. Since `q(E)=rank(E)`, the constant-coordinate term cancels.
A positive weighted sum of prefix defects implies a positive defect at some
prefix having a positive successive coefficient difference. Exact physical
ranks and the existing conditional-rank consumer can certify that prefix.

For a failed restricted master, merely adding its entire dual as a source row
would be wrong. Each such normal must be repriced over the full domain.
Likewise, reaching a round/time cap is inconclusive. The two decisive stopping
conditions are an exact nonnegative basis mixture matching every target
coordinate, or an independently checked globally priced rank violation.

If repeated duals expose omitted positive coordinates, an exact support-face
check is a useful implementation option rather than another numerical run:
jointly contract all target-one elements, delete target-zero elements, and
check that every positive coordinate can lie in a basis of that face. A
failure yields a literal rank obstruction; otherwise a bounded set of basis
extensions can cover missing coordinates. Any such preprocessing needs its
own exact input/physical proof and is not presumed present in the current
driver. No iteration bound follows merely from this suggestion.
