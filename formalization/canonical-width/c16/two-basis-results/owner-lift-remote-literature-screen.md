# Low-load primary-source screen, 2026-10-30

This is a remote HTML reading record, not a new algorithm or source certificate. No PDF was downloaded, no local solver was run, and no central catalogue was changed. A small title/author/identifier search of the existing source and question indexes found no duplicate for the two screened papers. The source question remains open.

**Frank–Murota, A Discrete Convex Min-Max Formula for Box-TDI Polyhedra.** Read the complete [arXiv v3 HTML](https://arxiv.org/html/2007.03507v3), dated 27 January 2021: introduction, Sections 2–6, appendix, and references. Its exact duality requires box-TDI structure. Section 4.3 computes a dual given an optimal primal. Section 1.2 asks for strongly polynomial primal algorithms for weighted square-sum on an M-convex set and ordinary square-sum on an M2-convex set. Sections 5–6 also propose algorithm development from their min-max formulas, including inverse optimization. The appendix's concrete-conjugate questions are answered within the paper, not outstanding questions.

The first algorithm question cannot safely retain current-open status: the same authors' [later primary paper, arXiv:2202.06561v2, Remark 4.4](https://arxiv.org/html/2202.06561v2#S4.SS3) states that the weighted discrete quadratic problem is already known strongly polynomial. This follow-up was consulted selectively, not fully screened. Its cited algorithm hypotheses still merit checking before implementation. Bounded searches found no resolution evidence for the M2 question; that is **current status unresolved by this review**, not proof it remains open.

**Lendl–Peis–Timmermans, Matroid bases with cardinality constraints on the intersection.** Read the complete [publisher-deposited HTML](https://pmc.ncbi.nlm.nih.gov/articles/PMC9237001/), DOI 10.1007/s10107-021-01642-1: introduction, Sections 2–6, both appendices, and references. The historical strongly polynomial recoverable-robust question is resolved by this paper. Section 5 explicitly asks whether the polymatroid problem with a norm bound on the difference remains tractable for arbitrary norms, particularly the Euclidean norm, and conjectures a convex-optimization approach. Bounded primary-source searches found no follow-up resolution; current status is unverified. The cardinality reductions and independent matching are not a proof of C16 mutual-dual compatibility.

**Applicability assessment (our reasoning).** The local owner split after eliminating its selected component is a weighted rank base polytope, as proved in `conditional-owner-lift-theory-review.md`. Retaining that component gives two intersecting bases; cross-pattern prescribed totals add another system. Neither screened source establishes that this augmented system is box-TDI or a submodular flow. A matching between two full physical bases exists automatically from the invertible pairing matrix, whereas a source frame requires all non-owner pairings to vanish. Thus importing independent matching would lose the feature we need.

**Formula caution.** In the Frank–Murota HTML, (5.18) displays a weighted-square fitting interval with radius 1. Direct expansion of `c*k^2` gives radius `c`. Treat this as an apparent formula/transcription error and use the general derivative condition instead. No implementation here depends on that display.

**Search boundary.** Searches covered the two precise Frank algorithm phrases, M2/intersection variants, the Lendl norm question, and Murota's current publication list. A negative search is not a resolution proof. Takazawa–Yokoi arXiv:1805.05528 was only a targeted consultation of its generalized-polymatroid hypotheses; it has not received a complete question screen here. The next permitted literature step is checking the original algorithms behind Remark 4.4, not an implementation inferred from terminology.
